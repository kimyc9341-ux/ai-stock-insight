# 📈 AI 주식 종합 예측 및 분석 에이전트

시장 데이터(실시간 시세), 재무제표 펀더멘털, 최신 시장 뉴스, 그리고 Google Gemini 추론 엔진을 결합하여 개별 종목의 상승 가능성을 심층 분석하는 에이전트 프로그램입니다.

---

## ✨ 핵심 기능 구현 현황

1. **📡 실시간 주가 API 연동 (`stock_service.py`)**:
   - 네이버 금융 공식 실시간 데이터 통신을 통해 현재가, 등락폭(▲/▼), 등락률, 체결 시간을 실시간 수신
2. **📊 재무제표 펀더멘털 분석 (`stock_service.py`)**:
   - 최근 결산 연도별 매출액, 영업이익, 당기순이익, 영업이익률, ROE, PER, PBR 자동 수집 및 비교
3. **📰 실시간 시장 뉴스 헤드라인 수집**:
   - 해당 종목의 가장 최근 언론사별 시장 뉴스 3~4건의 헤드라인과 핵심 요약 본문 추출
4. **🤖 Google Gemini API 심층 추론 & 스마트 규칙 엔진**:
   - 실시간 주가 + 재무 지표 + 시장 뉴스를 하나의 컨텍스트로 결합하여 3단계 종합 투자 분석 리포트 생성
   - `.env`에 `GEMINI_API_KEY`가 없을 때도 자체 **Smart Rules Engine**을 통해 안정적인 분석 보고서 제공
5. **🔍 종목 검색 및 대시보드 리포트**:
   - 종목명(예: `삼성전자`, `SK하이닉스`) 또는 6자리 종목코드 입력 시 종합 분석 리포트 즉시 출력

## 🚀 실행 방법

### 1. 터미널(CLI) 프로그램 실행
Windows PowerShell 또는 WSL2 Ubuntu 터미널에서 실행:
```bash
python main.py
```
- **메뉴 1**: 오늘의 상승 유망 8종목 실시간 시세 라이브 모니터링
- **메뉴 2**: 종목 검색 및 AI 심층 분석 리포트 (시세 + 재무 + 뉴스 + AI)
- **메뉴 3**: Google Gemini API 키 연동 가이드
- **메뉴 0**: 프로그램 종료
