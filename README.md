# 🐍 지렁이 게임 (Snake Game)

웹 브라우저에서 바로 즐길 수 있는 HTML5 Canvas 기반의 클래식 지렁이(스네이크) 게임입니다.

---

## 🎮 게임 조작법
- **이동:** `↑`, `↓`, `←`, `→` (방향키) 또는 `W`, `A`, `S`, `D`
- **일시정지 / 재개:** `Space`

## ✨ 게임 특징
- **점수 시스템:** 먹이를 먹을 때마다 10점씩 획득
- **속도 증가:** 점수가 올라갈수록 게임 진행 속도가 점차 빨라집니다.
- **최고 점수 저장:** 브라우저의 로컬 저장소(`localStorage`)에 최고 점수가 안전하게 기록됩니다.
- **간편한 실행:** 별도의 설치 과정 없이 `index.html` 파일을 더블 클릭하여 바로 플레이할 수 있습니다.

## 🛠️ 사용 기술
- HTML5 Canvas
- CSS3
- Pure JavaScript (Vanilla JS)
