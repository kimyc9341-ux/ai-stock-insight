      모의계좌 진단

      보유 비중은 현금을 포함한 총 평가액 기준이며, 평가손익은 매수원가 대비 차이입니다.

        보유 종목이 없습니다. 모의매수 후 하락 시나리오를 실험할 수 있습니다.

        한 종목 하락 시나리오

        선택한 종목만 하락하고 현금과 다른 종목의 가격은 그대로라고 가정합니다.

        🚨 내 계좌 응급실 : 물린 종목 심폐소생 & 물타기 시뮬레이터

        현재 보유 중인 종목의 매수단가와 수량을 입력하면, 현재 실시간 시장가와 비교하여 정확한 손실률을 진단하고, 목표 평단가 도달을 위한 추가 매수 처방전을 즉시 도출해 드립니다.

        🌐

        GitHub Pages 프론트엔드

        `index.html` 단일 SPA와 4,332개 종목 장부(`stocks.json`)를 무료 호스팅합니다. 사용자 행동은 `UserActivityTracker`가 즉시 기록합니다.

        Render FastAPI 백엔드

        `api_server.py`가 로그인/토큰 검증(`X-Admin-Token`), 네이버 시세 CORS 프록시, DART 공시 및 Gemini AI 분석을 안전하게 중계합니다.

        🗄️

        Supabase PostgreSQL DB

        회원 정보(`app_users`), 심사용 계정(`app_review_accounts`), 감사 로그(`app_audit_logs`), 관심종목·모의계좌(`app_user_portfolios`)를 중앙 저장합니다.

        🛡️

        실시간 보안 · 권한 통제
