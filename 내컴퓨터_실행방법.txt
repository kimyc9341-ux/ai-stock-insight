🩺 [내 계좌 심폐소생술] 집/개인 컴퓨터에서 바로 실행하는 방법
=============================================================

1. 압축 풀기
   - 다운로드받은 '내계좌심폐소생술_풀패키지_집에서작업용.zip' 파일의 압축을 
     원하는 폴더(예: 바탕화면)에 풀어줍니다.

2. 웹 화면 바로 열기 (설치 없이 바로 실행 가능)
   - 폴더 안의 'index.html'을 더블클릭하면 크롬, 엣지, 웨일 등 
     웹 브라우저에서 실시간 시세, 차트, 물타기 계산기, 모의투자가 즉시 동작합니다.
   - 'architecture.html'을 더블클릭하면 3분 요약 작동 원리 가이드가 열립니다.

3. 파이썬(Python) 환경 및 자동 수집기 실행 방법 (선택 사항)
   - 파이썬이 설치된 환경에서 최신 데이터를 새로 크롤링하고 싶을 때:
     ① 터미널 또는 명령 프롬프트(cmd)에서 해당 폴더로 이동
     ② 필수 패키지 설치:
        pip install requests beautifulsoup4 pandas
     ③ 최신 주식 데이터 수집 실행:
        python build_data.py
     ④ 백엔드 서버 구동 시:
        python main.py

4. 프로젝트 주요 파일 설명
   - index.html : 메인 서비스 화면 전체 (HTML/CSS/JS 프론트엔드)
   - architecture.html : 시스템 구조 및 작동 원리 시각화 대시보드
   - build_data.py : 4,332개 코스피/코스닥 전종목 시세 & 공시 수집기
   - stock_service.py : KIS 모의투자 및 DART 전자공시 데이터 처리 모듈
   - main.py : 로컬 API 서버
   - data/stocks.json : 4,332개 종목의 종합 데이터베이스
   - assets/ : 스탁챗 고화질 공식 로고 및 앱 아이콘
=============================================================
